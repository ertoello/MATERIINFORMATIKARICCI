BAB III · PENGANTAR

Teknologi Informasi dan Komunikasi

Teknologi Informasi dan Komunikasi (TIK) mencakup teknologi yang digunakan untuk mengumpulkan, mengolah, menyimpan, menyampaikan, dan menerima informasi.

01

Perangkat keras

Bagian fisik komputer, seperti monitor, papan ketik, tetikus, dan media penyimpanan.

02

Perangkat lunak

Program yang mengatur kerja komputer dan membantu pengguna menyelesaikan tugas.

03

Pengguna

Orang yang mengoperasikan komputer serta menentukan tujuan penggunaannya.

A · ANTARMUKA PENGGUNA

A. Pengenalan Antarmuka Pengguna (User Interface)

Antarmuka pengguna (User Interface atau UI) adalah bagian sistem yang menjadi penghubung antara pengguna dan komputer. UI yang baik harus mudah dipahami, praktis, komunikatif, dan mendukung pekerjaan pengguna.

Menu dan ikon

Menyajikan perintah dalam bentuk teks atau simbol yang mudah dikenali.

Papan ketik dan tetikus

Memungkinkan pengguna memasukkan perintah serta memilih objek pada layar.

Gestur dan suara

Mendukung interaksi melalui sentuhan, gerakan, atau perintah suara.

B · FOLDER DAN FILE

B. Folder dan File

Folder adalah wadah untuk menyimpan file atau folder lain. File adalah kumpulan data yang disimpan dalam media penyimpanan dan diolah menggunakan aplikasi yang sesuai.

Folder

Mengelompokkan file agar tersusun rapi dan mudah ditemukan.

File

Dapat dibuat, dibaca, diubah, disalin, dipindahkan, dan dihapus.

File Manager

Pada Windows, pengelolaan file dilakukan menggunakan File Explorer.

B · EKSTENSI FILE

Ekstensi File

Klik kartu untuk melihat jenis data yang diwakilinya.

.DOC dan .DOCX digunakan untuk dokumen pengolah kata.

B · PENGELOLAAN FOLDER

Pengelolaan Folder

Folder sebaiknya diberi nama yang jelas, berisi file sejenis, dan tidak menggunakan nama yang terlalu panjang. Pengelompokan dapat dilakukan berdasarkan jenis, fungsi, atau waktu pembuatan.

01Beri nama jelas
02Kelompokkan file
03Hindari nama panjang

Contoh: gunakan folder bernama “Gambar” untuk menyimpan koleksi foto dan ilustrasi.

A · JENIS USER INTERFACE

Command Line Interface (CLI)

CLI merupakan antarmuka berbasis teks. Pengguna berinteraksi dengan sistem dengan mengetikkan perintah tertentu pada baris perintah.

CLI menggunakan memori dan sumber daya perangkat keras yang relatif kecil. Antarmuka ini efisien bagi pengguna yang memahami sintaks perintah.

Keterbatasannya adalah pengguna harus mengingat perintah dengan tepat dan tampilannya kurang menarik secara visual.

  1. 01Contoh
    Command Prompt dan terminal.
  2. 02Keunggulan
    Ringan dan efisien.
  3. 03Kekurangan
    Memerlukan pengetahuan perintah.

A · JENIS USER INTERFACE

Graphical User Interface (GUI)

GUI menggunakan unsur visual, seperti jendela, ikon, menu, tombol, kursor, tetikus, dan perangkat penunjuk lainnya.

Pilih karakteristik untuk melihat penjelasannya.

A · JENIS USER INTERFACE

Voice User Interface (VUI)

VUI memungkinkan pengguna memberikan perintah kepada perangkat melalui suara. Teknologi ini dapat digunakan untuk membuka aplikasi, melakukan pencarian, atau menjalankan fungsi tertentu.

Keunggulan

Mempercepat pemberian perintah dan dapat digunakan tanpa menyentuh perangkat secara langsung.

Keterbatasan

Perintah dapat keliru apabila suara tidak terdengar jelas atau sistem salah mengenali ucapan.

Penggunaan bijak

Periksa kembali hasil perintah dan lindungi informasi pribadi saat menggunakan layanan suara.

C · INTERNET

C. Peramban (Browser) dan Mesin Pencari (Search Engine)

Peramban dan mesin pencari membantu pengguna mengakses serta menemukan informasi di internet. Pengguna perlu memeriksa sumber dan menggunakan informasi secara bertanggung jawab.

Peramban

Aplikasi untuk membuka dan menampilkan halaman web, misalnya Google Chrome, Mozilla Firefox, dan Microsoft Edge.

Mesin pencari

Layanan untuk menemukan informasi berdasarkan kata kunci, misalnya Google, Bing, dan Yahoo.

Alamat web

URL diketikkan pada address bar untuk mengakses halaman tertentu.

C · PERAMBAN

Peramban (Browser atau Web Browser)

Peramban adalah perangkat lunak yang mengambil dan menampilkan halaman web. Ketika URL dimasukkan, peramban meminta data kepada server dan menampilkan dokumen HTML kepada pengguna.

Selain membuka laman, peramban dapat menyimpan bookmark, mendukung autentikasi, membuka file HTML, CSS, dan JavaScript, serta terintegrasi dengan mesin pencari.

URL -> server -> halaman web
  1. 01Masukkan URL
    Ketik alamat pada address bar.
  2. 02Ambil data
    Browser meminta data dari server.
  3. 03Tampilkan halaman
    HTML dirender menjadi laman web.

C · MESIN PENCARI

Mesin Pencari (Search Engine)

Mesin pencari menemukan informasi sesuai kata kunci yang dimasukkan pengguna. Prosesnya terdiri atas tiga tahap utama.

01Crawling
Mengumpulkan data dari halaman web.
02Indexing
Mengelompokkan data dalam indeks.
03Ranking
Mengurutkan hasil yang relevan.

Catatan: gunakan kata kunci yang spesifik dan bandingkan informasi dari beberapa sumber.

D · KOMUNIKASI DIGITAL

D. Surel (E-Mail)

Surel atau surat elektronik adalah sarana untuk mengirim dan menerima pesan melalui internet. Pesan dapat berupa teks, gambar, dokumen, atau video.

Fungsi surel

Digunakan sebagai identitas digital, verifikasi layanan, dan sarana pendaftaran pada situs atau media sosial.

Contoh layanan

Gmail dan Yahoo Mail merupakan contoh layanan surel yang banyak digunakan.

Etika surel

Gunakan subjek yang jelas, bahasa yang sopan, dan lampiran yang aman.

D · MEKANISME SUREL

Cara Kerja Surel

01Pengirim
Komputer membuat dan mengirim pesan.
02Mail server
Server pengirim meneruskan pesan melalui DNS.
03Penerima
Server penerima mengirim pesan ke komputer penerima.

Jenis surel: plain text dan HTML berdasarkan format; Gmail dan Yahoo berdasarkan layanan; forwarding, POP, dan web based berdasarkan mekanisme.

D · PRAKTIK

Membuat Surel

Pendaftaran akun surel dilakukan dengan mengisi identitas, membuat kata sandi, melakukan verifikasi nomor telepon, melengkapi data yang diperlukan, dan menyetujui kebijakan privasi.

  1. 01Isi identitas
    Masukkan nama dan data yang diminta.
  2. 02Buat kata sandi
    Gunakan kata sandi yang kuat dan tidak mudah ditebak.
  3. 03Verifikasi akun
    Gunakan nomor telepon aktif jika diminta.
  4. 04Setujui kebijakan
    Baca dan pahami kebijakan privasi layanan.

E · APLIKASI PERKANTORAN

E. Aplikasi Perkantoran (Office Suite)

Aplikasi perkantoran adalah kumpulan perangkat lunak yang saling terintegrasi untuk mendukung pekerjaan, seperti mengolah kata, angka, presentasi, basis data, dan publikasi.

Pengolah kata

Untuk membuat dan mengedit dokumen, laporan, serta surat.

Pengolah angka

Untuk menghitung, mengelola tabel, dan menyajikan data dalam grafik.

Presentasi

Untuk menyusun informasi dalam bentuk slide yang komunikatif.

E · SEJARAH

Sejarah Pengolah Kata

Pengolah kata berkembang dari mesin mekanik menjadi perangkat lunak digital yang mampu menyimpan dan memformat dokumen dengan lebih cepat.

1714Henry Mill
Memperoleh paten gagasan mesin penulis.
Abad ke-19Christopher Sholes
Mengembangkan mesin ketik.
1950IBM
Memperkenalkan mesin pengolah kata elektromekanis.

Perkembangan berikutnya: Mag Card IBM pada 1969, floppy disk pada 1970, dan komputer dengan layar CRT pada 1978.

E · PERANGKAT LUNAK

Perangkat Lunak Pengolah Kata

Pada era komputer pribadi, perangkat lunak seperti WordStar, Star Information System, dan Microsoft Word membantu pengguna membuat dokumen secara digital.

Pilih operasi untuk melihat penjelasannya.
